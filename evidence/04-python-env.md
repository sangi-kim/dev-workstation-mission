# 4. 파이썬 환경 구축 및 테스트 결과

## 1. 파이썬 버전 확인
시스템에 설치된 파이썬 버전을 확인하였습니다.
- **명령어**: `python --version`
- **결과**: `Python 3.15.2`

## 2. 가상환경(venv) 설정
프로젝트별 독립된 환경을 위해 가상환경을 생성하고 활성화하였습니다.
- **생성 명령어**: `python -m venv venv`
- **활성화 명령어**: `source venv/Scripts/activate`
- **상태 확인**: 터미널 프롬프트에 `(venv)` 표시 확인 완료

## 3. 패키지 설치 및 목록 (`pip list`)
외부 라이브러리(`requests`) 설치 후 정상적으로 로드된 패키지 목록입니다.
